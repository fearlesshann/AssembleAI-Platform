# T3 BFF 登录与服务端会话实施计划

> **For agentic workers:** 使用既有 SPEC 与本计划继续实现，不重新确认已确定的身份方案。各任务在同一功能分支协作，文件所有权明确分离。

**Goal:** 实现可接入 Keycloak / 标准 OIDC 的 BFF 登录、服务端会话、状态查询与 CSRF 保护退出。

**Architecture:** ASP.NET Core 官方 OIDC handler 执行 Code + PKCE 与令牌校验，Cookie handler 仅在浏览器存服务端 ticket 引用。开发模式使用有界内存 ticket store；生产使用 PostgreSQL 加密 ticket 与显式持久化密钥。权限继续每次读取平台仓储。

**Tech Stack:** net10.0、Microsoft.AspNetCore.Authentication.OpenIdConnect 10.0.14、现有 Npgsql 10.0.0。

**Spec:** `SPEC.md` I.identity / I.authz，V4 / V6 / V14 / V20 / V25；`docs/architecture/t1-decisions.md` §2。

## 约束与验收重点

- 主体保持唯一原始 `iss` / `sub`，不读伪造身份头，不自动授予租户成员关系。
- 浏览器响应、Cookie 与跳转中不返回 access / refresh / ID token；会话最长 8 小时、不滑动续期。
- Production 仅 HTTPS，密钥需显式目录与加密证书；Development 仅允许 loopback HTTP 和进程内临时状态。
- 无认证 API 返回 401；配置默认关闭，缺配置不伪造成功。
- `GET /bff/login?returnUrl=/` 仅接受站内路径，回调地址来自配置的 PublicOrigin。
- `GET /bff/csrf` 返回 requestToken / headerName，Cookie 为 HttpOnly；`GET /bff/session` 返回认证主体显示信息，无令牌。
- `POST /bff/logout` 同时校验固定 PublicOrigin 和 `X-CSRF-TOKEN`，撤销本机会话后返回 204；不宣称注销身份中心 SSO。GET 退出无效。
- 本阶段不改模板演示登录，不实现刷新令牌、租户切换与内部签名凭证；T3 保持进行中。
