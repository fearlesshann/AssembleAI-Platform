# T12 企业知识库问答 Implementation Plan

> **For agentic workers:** Use the existing authorized implementation workflow; execute each item with its tests. Shared files have one owner.

**Goal:** 从实际上传的制造业测试 PDF / DOCX 检索授权内容，经过模型网关回答并给出可定位原文引用。

**Architecture:** 平台持有文档 ACL、对象、持久任务、索引与检索审计；独立 FastAPI 应用持有解析、固定本机 embedding 和问答编排。PostgreSQL 是任务事实源，RabbitMQ 承载可重复通知；文档与任务 revision 防止删除后的旧结果重新发布。问答只接收当前授权片段，模型前和最终交付前复核全部上下文文档。

**Tech Stack:** ASP.NET Core / PostgreSQL 17 + pgvector 0.8.7 / MinIO / RabbitMQ / Python 3.13 / ONNX Runtime CPU / Vue 3。

**Spec:** [SPEC.md](../../../SPEC.md) §I.knowledge、I.jobs、I.gateway、I.models、I.authz、I.portal、I.deploy；V2、V4、V6、V8、V9、V11、V12、V14–V20、V22–V26、V31、V32。

## Global Constraints

- 本机进程开发，不要求 Docker；新增依赖固定版本与摘要。密钥仅环境变量，测试对象明确标注为合成数据。
- 原文限 5 MiB；支持 DOCX、文本层 PDF、UTF-8 TXT / Markdown；扫描、加密、旧 DOC 明确拒绝。
- E5 profile `e5-small-dd476dd0-384-v1`，384 维；固定模型与 tokenizer 摘要，512 token 含前缀 / 特殊 token；不静默截断原文。
- 每批最多 8 个原始片段、64 个 token 子片段；每文档最多 4096 个索引片段。30 秒任务预算，60 秒租约，最多 3 次连续失败；进度提交后重置失败次数。
- 问题最多 1000 字；最多 5 个检索命中。检索 30 秒、内部检查 3 秒；Python 客户端分别 35 / 5 秒；模型 120 秒、问答总限 180 秒、心跳 10 秒。
- 无回答历史持久化。问题、正文、向量、能力、模型凭据不得写入业务审计。

## Review Focus

- 删除发生于解析、embedding 或模型等待期间：旧 revision / lease 不得发布或交付。
- 多条 grant 的资源与组织范围不可交叉组合；授权过滤必须发生于向量排名前。
- Emoji 和 overlap 的跨语言长度口径必须一致，合法解析结果不得无原因失败。
- 重复 RabbitMQ 通知、租约回收、服务短暂不可用不产生重复有效索引；终态失败可诊断。
- 同一页面切账号 / 租户、迟到响应、焦点复核失败时清除旧答案与引用；主题改变保留当前内容。

## Task 1: 索引任务、向量检索与活动委托

**Files:** `services/platform/Knowledge/*`、`services/platform/Gateway/*`、`deploy/postgres/migrations/0011_knowledge_index.sql`、`tests/platform/*Knowledge*`；平台代理独占。主代理接 `Program.cs`、迁移入口与 readiness。

**Interfaces:** 私有 `/internal/index` 接收 `{chunks:[{index,text,locator}]}`，返回 `{profile,dimensions,segments:[{chunkIndex,segmentIndex,text,locator,embedding}]}`；`/internal/embed-query` 接收 `{query}`，返回 `{profile,dimensions,embedding}`。静态 parser key 验证服务身份。核心迁移存 384 维 real 数组，搜索用 pgvector 的显式 vector 转换与余弦距离，保留核心迁移与扩展安装边界。

独立 `X-Knowledge-Delegation` 由显式 `GatewayOperation.KnowledgeRead` 签发。`/internal/knowledge/search` 接收 `{question,limit}`，返回 `{requestId,authorizationVersion,profile,hits:[{chunkId,documentId,documentRevision,fileName,locator,text,score}]}`。`/internal/knowledge/check` 接收 `{authorizationVersion,profile,documents:[{documentId,revision}]}`，复核全部上下文与活动父调用；原 JWT / model / connector 能力不能替代。
