# T11 ChatBI Implementation Plan

**Goal:** 独立 ChatBI 前后端把自然语言问题转成受控查询，经真实授权模型和只读数据连接器执行，展示数据、查询依据和明确状态。

**Architecture:** ChatBI 为独立 Vue UMD / FastAPI 发布物，沿用样例接入模式与平台样式。Gateway 为显式白名单操作分别签发模型与数据委托；Python 验证原业务请求后，只使用活动能力回调平台。模型生成严格 JSON 查询，所有业务数据只交给连接器与当前浏览器；结构化验证、权限与工厂过滤由平台再次执行。SSE 传阶段与暂存行，最终 complete 前复核查询授权 / 配置，前端只在完整完成后展示结果。

**Tech Stack:** 现有 Vue 3 / TypeScript / Vite / qiankun / app-sdk，FastAPI / httpx / Python 3.13，.NET 10 / PostgreSQL；无新增第三方依赖。本机进程、当前 codex/t3-bff 分支。

**Spec:** SPEC T11、D5、I.chatbi/I.connectors/I.models/I.gateway/I.identity/I.audit；V2,V4,V5,V6,V7,V8,V9,V12,V14,V18,V19,V20,V21,V25,V29。继续用户确认的制造业测试数据与提供的 DeepSeek 模型。

## Design decisions

- 独立 apps/chatbi/frontend 和 apps/chatbi/backend；后端采用已有经过验证的认证 / 模型客户端模板，明确版本维护，不运行 sample 应用作为 ChatBI。前端独立与嵌入共用同一发布物，显式连接、不自动创建运行。
- 数据委托使用独立 registry，内部复用已验收的摘要能力算法；GatewayOperation.ConnectorDatasetIds 白名单与 X-Connector-Delegation 头独立于 ModelIds / X-Model-Delegation。原始业务 JWT 和浏览器伪造头均不能查询数据。
- 内部 GET /internal/connectors/datasets 返回当前活动调用可见且有三类交集权限的数据集元数据；不暴露物理表、组织 UUID、连接信息。POST /internal/connectors/{sourceId}/datasets/{datasetId}/query 共用 T10 执行器；返回可信 authorizationVersion/configurationRevision 守卫版本。POST 同路径 /check 校验这两版本及实时权限 / 父调用，不查询业务数据。
- 委托查询审计增加 source={appId,releaseVersion,runId,gatewayRequestId}；迁移 9 四字段全空或全有效。直接 BFF 审计来源保持空。
- ChatBI GET /datasets 返回 {items:[{sourceId,datasetId,displayName,columns:[{name,type}],maxRows}]}；POST /ask 接 {datasetId,question}，正文 ≤8KiB、问题 ≤1000 字、总执行 150 秒。metadata 与 ask 操作分别配置业务权限 chatbi:use；ask 同时有模型和数据集白名单。
- 模型一次调用只生成 T10 查询对象（columns/filters/metrics/limit），或 {refusal:"unsupported_question"}。禁止 Markdown 包裹、未知字段、SQL、替换数据集/身份和超过100行。非法计划不会执行数据源，不进行自动修复 / 重试。模型仅接收问题与获授权字段定义，不发送业务行。
- 查询 JSON 保留原始小数字面值传给平台；结果数值在 Python 转为十进制文本后送浏览器，避免 Python/JavaScript 浮点舍入。展示原始 queryText 作为依据，所有文字转义，不解释 HTML / Markdown。
- SSE delta: {kind:"stage",stage:"planning"|"querying"|"receiving"}; delta: {kind:"rows",rows:(string|null)[][]}。complete: {requestId,modelRequestId,queryRequestId,sourceId,datasetId,datasetName,columns:string[],rowCount,queryText,scope:"当前授权工厂",summary:string}。每事件 ≤32KiB；前端暂存行且只在 complete 完整匹配后提交展示。错误 / 取消 / 断流清空暂存，缺 complete 不算完成。
- 页面为数据分析工作区：数据集选择、提问输入、示例问题、执行阶段、结果表和折叠依据；浅暗主题、390px布局、键盘可达。状态不暴露内部凭据 / 服务细节。
- D5 基准：A两行 100/200 与2/3，B和异租户不可见；合计产量300，2026-11-02产量200，按产线合计300。恶意模型计划与越权dataset拒绝。真实模型验收只发三个合成问题，无业务数据；先协议夹具全面通过再调用实际供应商，不将夹具当实际模型。

## Review focus

- 原业务JWT过期但活动能力仍有效；父调用结束后不能metadata/query/check重放。
- 后端等待模型时撤权 / 退出，连接器必须拒绝后续查询；流末重新核验数据权限版本。
- 缺 complete、非法列/行、过大事件、切租户或卸载后的迟到响应不得恢复旧结果。
- 模型字段与数值不可信，不能以Prompt替代强制过滤；数字跨Python/JS后保留精度。
- 独立页面用同一BFF与可信静态发布物；新增应用靠部署注册，不硬编码门户入口授权。
