# T6 · 授权应用门户实施计划

> 按已授权 SPEC 继续实现；由根线程集成，后端目录、门户界面和本机代理分别实施与复核。

**目标：** 默认首页使用真实 BFF 登录和租户选择，展示当前用户获准使用的应用，提供分类、搜索、详情和固定版本运行入口。

**方案：** 沿用 Vue 3 / Element Plus / qiankun 与已有 BFF / 注册 / 网关。独立目录读接口执行服务端过滤；门户只筛选已授权结果。默认入口替换演示模板，原模板置于 `/reference-ui/`，工程接入验证保留 `/workspace/*`。本轮不引入路由或状态库。

**依据：** SPEC C6、I.portal / I.registry / I.identity / I.gateway、V4,V6,V10,V11,V15,V19,V25。T7 继续负责完整跨语言 SDK、受控应用请求能力和应用模板验收；本轮运行宿主复用现有生命周期加载机制，不向应用传递认证凭据。

## 契约与实施决定

- `GET /api/platform/v1/tenants/{tenantId}/catalog` → `{items:[{appId,name,releaseVersion,category,description}],categories:string[]}`；`GET /catalog/{appId}` → 同一展示 DTO。Cookie 身份、服务端已选租户、有效成员关系；每次读取全部入口权限，精确 application/appId + tenantWide。仅当前启用、全局 published 且部署目录可信的版本可见。类别仅来自可见结果。
- 列表不缓存授权，最多 500 个授权应用，超限安全 503，不静默截断。先限定当前用户应用授权对应 ID，再流式校验全部权限与部署声明；3 秒总查询预算。T6 在该有界完整集合上本地搜索和分类；大目录分页留规模需求明确后实施。
- 租户不匹配 / 无成员关系 403；隐藏与不存在详情均 404；未登录 401；依赖不可用 503。no-store / nosniff，无下游地址、原始异常或凭据。
- 运行使用现有 T5 POST runs；点击才创建，不能把前端地址跳转当作授权。运行对象仅保留内存；刷新运行页要求重新打开，不能隐式重复创建。资源入口必须精确匹配应用与发布物版本；只从已取得的运行响应加载同源版本化入口。
- 切租户、退出、失效清空目录 / 详情 / 运行并取消旧请求；迟到响应不能恢复旧租户内容。焦点恢复重新读取会话与租户。浏览器持久存储仅主题偏好，CSRF 令牌仅内存。
- 默认浅色，延续 C6 220px 侧栏、密集列表、品牌紫色及中性色阶；暗色完整覆盖 Element Plus。系统中文字体、清晰焦点、状态文案、390px 布局与 reduced-motion。页面不展示技术配置字段。
- 本机 Vite / 构建预览按部署配置代理 `/bff`、`/signin-oidc`、`/api` 到固定 loopback 平台地址，保留 Cookie / Origin / 重定向和流；不接受请求指定目标，不代替生产代理。PublicOrigin / 回调使用浏览器入口。无后端配置明确 503。
